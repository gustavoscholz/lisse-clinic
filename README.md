# Lisse Clinic

Landing page da Lisse Clinic construída com React, TypeScript, Tailwind CSS e Vite a partir do layout original do Figma.

## Desenvolvimento

```bash
npm install
npm run dev
```

O servidor local utiliza `http://localhost:5173`.

## Modos disponíveis

- Início: `http://localhost:5173`
- Harmonização: `http://localhost:5173/?modo=harmonizacao`
- Faloplastia: `http://localhost:5173/?modo=faloplastia`
- Emagrecimento: `http://localhost:5173/?modo=emagrecimento`

## Verificações

```bash
npm run lint
npm run build
```

Os links externos permanecem apenas visuais nesta primeira versão e serão configurados quando os destinos definitivos forem fornecidos.
